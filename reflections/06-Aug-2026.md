## Topics Discussed

- SSH and HTTPS protocols
- Raster and vector graphics
- Image generation requirements

## Reflection

This class helped me connect several foundational ideas used in computer graphics and software development. Learning about **SSH and HTTPS** helped me understand that accessing a GitHub repository is not just about Git commands, but also about the **protocol and authentication method** used to communicate securely with GitHub.

The discussion on raster and vector graphics also clarified that images can be represented in fundamentally different ways. Raster images store information **pixel by pixel**, while vector graphics describe the image using **mathematical definitions**. This helped me understand why vector graphics can scale without losing quality.

Overall, the class gave me a better understanding of both the **tools used to manage code** and the **basic ways in which digital images are represented**.
