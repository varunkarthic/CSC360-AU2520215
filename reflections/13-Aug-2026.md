## Topics Discussed

- Apache Maven
- Maven project structure
- The `pom.xml` file

## Reflection

This class helped me understand that a Java project is more than a collection of source files. Maven gives the project a **predictable structure** and provides a consistent way to manage and build it.

The `pom.xml` file initially appeared to be only an XML configuration file, but I understood that it acts as the **central definition of the project**. Instead of manually managing every library and build setting, Maven can read this file and handle them systematically.

I now have a basic foundation for working with Maven projects. With further practice, I would like to understand Maven's **dependencies, plugins, and build lifecycle** in greater detail.
