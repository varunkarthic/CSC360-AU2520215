## Topics Discussed

- Calculating the square's vertices

## Reflection

This class helped me understand how a basic geometric idea can be translated into coordinate-based logic. Although drawing a square appears simple, the program must first determine exactly where each vertex should be placed. This also showed me that understanding the mathematical reasoning behind graphics code makes the implementation easier to explain, verify, and modify.
