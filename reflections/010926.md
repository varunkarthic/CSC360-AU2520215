# Reflection - 1 September 2026

## Topics Discussed

- Converting three text equations into a drawn triangle
- Handling right-click events on a JavaFX canvas
- Connecting points with directed arrows
- Representing and drawing a binary tree

## Reflection

This class showed me that a graphics program is often a combination of user interaction, mathematical processing, and visual output. The triangle exercise was particularly useful because the user does not provide coordinates directly. Instead, the program has to interpret three equations, calculate their pairwise intersections, and use those intersections as vertices. This made the connection between algebra and computer graphics much clearer.

I also learned that text input creates responsibilities beyond drawing. The application must handle invalid syntax, parallel lines, and equations that do not form a valid triangle. This reinforced the idea that a graphical program still needs careful input validation and a clear model of its data.

The circle exercise helped me understand JavaFX event handling in a practical way. A right-click provides a coordinate, but producing a useful diagram requires storing that coordinate and redrawing the complete scene when necessary. Connecting circles with arrows introduced vectors and angles, because the arrowhead must point in the correct direction and should meet the boundary of the destination circle neatly.

The binary tree exercise connected recursion with visual structure. A tree is naturally recursive because each child can itself be the root of another tree. Drawing the parent-child edges before the nodes made the rendering order important, while calculating positions from the available region showed how a data structure can be converted into a readable layout.

Overall, the class helped me see that drawing shapes is only one part of graphics programming. The more important design is the path from input, to data model, to geometric calculation, to rendering. This approach will be useful for larger interactive graphics applications.
