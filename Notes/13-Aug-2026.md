## Introduction to Maven

In this class, we installed **Apache Maven** and used it to create our first **Java project using Maven**.

Maven is a **build automation and project management tool** commonly used for Java projects. It provides a standard project structure and keeps the project's configuration in a central file.

---

# Maven Project Structure

We explored the basic structure of a Maven project and understood the purpose of its main components:

- `src/main/java` → Contains the main Java source code.
- `src/test/java` → Contains test code.
- `pom.xml` → Stores the project's configuration.
- `target` → Contains files generated when the project is compiled or packaged.

Using a standard structure makes Maven projects easier to understand, build, test, and maintain.

---

# The `pom.xml` File

`pom.xml` stands for **Project Object Model**. It is the central configuration file of a Maven project.

It can describe:

- The project's identity, such as its name and version.
- The Java version and build configuration.
- External libraries or **dependencies** required by the project.
- Plugins and other instructions Maven uses while building the project.

We gained a basic understanding of how the file is structured and how it controls the Maven project.
