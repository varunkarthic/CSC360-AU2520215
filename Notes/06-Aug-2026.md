# GitHub — SSH vs HTTPS Protocols to Access Repositories

*Thursday, 6 August 2026*

## SSH

**SSH (Secure Shell)** is a network protocol that enables you to securely access and execute commands on another device over a network.

HTTPS is essentially the **HTTP protocol wrapped with a security layer**, while SSH is primarily used for **secure remote access** and authentication using a **public–private key pair**.

### SSH Keygen

`ssh-keygen` is used to generate a **public and private key pair**.

By default, if no path is specified, it creates a `.ssh` folder in the user's home directory containing two key files:

* `.pub` file → **Public key**
* File without an extension → **Private key**

# Vector Graphics vs Raster Graphics

## Raster Graphics

Raster graphics are essentially represented as a **matrix of pixels**, where each element stores information about a particular pixel.

## Vector Graphics

Vector graphics define images using **mathematical logic, shapes, and equations**, which are rendered at runtime.

Because the image is mathematically defined rather than stored as fixed pixels, its quality is preserved regardless of the **screen resolution or display size**.
